## Facts (with paths)

1. **Monorepo layout.** pnpm workspace (`pnpm-workspace.yaml`), TypeScript. Top level: `apps/` (4 apps: `cli`, `desktop`, `desktop-host`, `web`), `packages/` (~60 package groups), `vendor/` (vendored framework libs), `docs/subsystems/` (per-subsystem references), `snapshots/`, `benchmarks/`, `.agents/notes/` (dated design records). Repo tagline: "DeepSeek Harness: Everything is a Plugin." Version at HEAD: `0.2.1-alpha.1`.

2. **ACP server package.** `packages/acp/acp/` = npm `@deepseek-ai/dsh-acp@0.2.1-alpha.1`, self-described as "Automation-only Agent Client Protocol server for driving DeepSeek Harness agents over JSON-RPC stdio" (`packages/acp/acp/package.json`). Built on `@agentclientprotocol/sdk@1.4.0`. Source map: `src/index.ts` (plugin entry, `AgentSideConnection` wiring, per-session records, prompt admission/settlement, teardown), `src/session.ts`, `src/updates.ts`, `src/content.ts` (wire-content admission/projection incl. image validation), `src/codec.ts` (turn-ending → ACP `stopReason`), `src/mcp.ts`, `src/model-control.ts`. Tests in `packages/acp/acp/tests/` (approval, bridge, multi-session, turns, updates).

3. **Launch path.** The ACP server is started as a Cordis *profile*: `pnpm dsh --profile acp`. The CLI is `apps/cli` = `@deepseek-ai/dsh`, bin `dsh` (`apps/cli/package.json`). The `acp` profile is bundle `packages/bundle/acp-app/` (`@deepseek-ai/dsh-acp-app`), layered on `dsh-base` via `cordis.patch.yml`; it mounts session persistence, reserves stdout for newline-delimited ACP JSON-RPC frames, binds stdin EOF + SIGINT/SIGTERM to bounded shutdown, and disables HMR so one stdio connection never sees a replaced bridge. Shipped default route: provider `deepseek-official`, model `deepseek-v4-flash`. `dsh --profile acp --help` exits without claiming stdio.

4. **ACP v1 surface.** Multi-session per connection (`packages/acp/acp/README.md`): `initialize`, `authenticate` (immediate success — no auth), `session/new` (absolute `cwd`; stdio and Streamable-HTTP MCP declarations validated before publication; MCP entry commands/URLs are trusted by declaration), `session/list` (newest-first paged persistent sessions; `sessionListPageSize` default 100; optional `cwd` filter), `session/resume` (canonical workspace verified; log restored without replaying updates), `session/close`, `session/set_config_option` (advertised `model` and `reasoning_effort`), `session/prompt` (one in-flight per session; route pinned per turn), `session/cancel` + `$/cancel_request`, `session/update` (committed messages/thoughts, generic tool lifecycle, config changes, context usage — serialized per session), `session/request_permission` (one-shot allow/reject). Package config fields: `provider`, `model`, `sessionListPageSize`. **Unsupported**: `session/load`, session deletion, fork, extra directories, SSE/ACP-transport MCP, modes, commands, plans, terminals, client filesystem ops, elicitation — no DSH-specific presentation data on the wire.

5. **In-repo ACP client.** `packages/subagent/subagent-acp/` (`dsh-subagent-acp`) spawns the same `acp` profile for out-of-process subagent delegation — the repo's own reference consumer of this server.

6. **Storage mechanism.** `packages/storage/` family: `storage/` = hub (`src/backend.ts` normative backend contract, `src/registry.ts` name→backend table, `tests/contract.ts` shared conformance suite; host-side `ctx.storage` only, `kv` sole facet, `StorageError` codes e.g. `backend-not-found`/`form-not-mounted`/`duplicate-backend`), `storage-json/` (`src/atomic.ts`, `single-unit.ts`, `per-record-unit.ts`), `storage-sqlite/` (`src/schema.ts`, `unit.ts`), `storage-domain/` (`src/domain.ts`, `spec.ts`, `events.ts`; served as `ctx.storageDomain`, per-domain backend routing). Session event logs are a separate family: `packages/session/session-persistence{,-jsonl}/`, `session-projection{,-cache}/`, `session-format-vN-to-vM/` migrations.

7. **Settings mechanism.** `packages/settings/settings/` (`@deepseek-ai/dsh-settings`): live plugin-config forms over `.volatile()`-declared fields (`src/schema.ts` form projection; `src/redact.ts` strips secret roles to presence markers; `src/index.ts` revisioned descriptors, stale-write refusal). Persists through the active profile's Cordis patch via `packages/boot/config-editor/`; one-time import of legacy `settings.yaml` → renamed `settings.yaml.imported`. API exposure via `packages/api/settings-controller/`; CLI inspection via `apps/cli/src/dump-config.ts`, `dump-config-schema.ts`.

8. **Profile mechanism.** Profiles are Cordis compositions (`cordis.yml` + patch files; examples `apps/cli/config/examples/*/cordis.yml`). Boot path: `apps/cli/src/profile-boot.ts` → `packages/boot/app-boot/` (`src/profile.ts`, `profile-resolution/{resolver,service,worker-bootstrap}.ts`, `profile-plugins.ts`, `profile-compatibility.ts`, `profile-sanitize.ts`). Shipped bundles in `packages/bundle/`: `base`, `headless`, `acp-app`, `sdk-app`, `sdk-minimal`, `web-app`. Agent personas/presets: `packages/preset/agent-preset-registry/` (`composition-inventory.ts`, `mount.ts`, `preset.ts`, `session.ts`) and `packages/preset/persona/`; ACP persona text is `You are a coding agent powered by the {{model}} model.` plus a `{{cwd}}` suffix (`packages/bundle/acp-app/README.md`).

9. **Plugin/extension mechanism.** Everything is a Cordis plugin: `@deepseek-ai/cordis@4.0.5-alpha.1` vendored at `vendor/cordis/` ("Meta-Framework for Modern JavaScript Applications", author Shigma, MIT) plus `vendor/{loader,include,timer,hmr,schemastery,cosmokit,group,logger-console}`. Plugin install/registry/patch/run-tree/GitHub-source operations live in `packages/boot/plugin-manager/` (`install-spec.ts`, `operations.ts`, `patch.ts`, `registry.ts`, `run-tree.ts`). Third-party extension execution: `packages/extensions/cordis-host-runner/` (sandboxed lifecycle, `sandbox.ts`, `lifecycle.ts`, `registry.ts`), `cordis-client-runner/`, `tool-cordis/` (tool surface), `ui-cordis/`; inventory via `packages/host/plugin-inventory/`. Typed Host↔Client remote calls: `packages/typert/{generator,loader,protocol,registry}/`.

10. **KPR integration-relevant notes.** ACP transport is stdio JSON-RPC only; stdout is protocol-pure by contract but "user plugins can violate stdout purity" is a documented limitation (`packages/bundle/acp-app/README.md`). `session/resume` needs the same profile persistence root; a close leaves persisted state resumable, client disconnect and Cordis disposal share one quiescent teardown. ACP profile adds no private method, capability, `_meta`, env var, or transport field — conformance-tested via the public ACP SDK (`apps/cli/tests/profiles/acp/`). Sessions persist as JSONL (`session-persistence-jsonl`), making on-disk logs inspectable. Config changes require restart (HMR off in `acp-app`).
